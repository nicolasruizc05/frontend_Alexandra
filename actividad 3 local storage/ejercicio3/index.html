Ejercicio 3. Catálogo de animales Desarrolle una aplicación para registrar diferentes animales. Solicitar: Nombre Especie Edad Hábitat URL de una imagen Por ejemplo: Nombre: Luna Especie: Perro Edad: 3 Hábitat: Doméstico Imagen: URL Cada animal debe almacenarse como un objeto dentro de un arreglo de animales. El arreglo completo debe guardarse en localStorage. Al presionar Mostrar animales, recuperar los datos almacenados y presentar cada animal mediante una tarjeta con imagen.
